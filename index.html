Guided lessons

How to use the simulator

  1. Start: click ⚡ Start engine (or turn the key to ON, wait for the bulb check and fuel pump prime, then START). Watch the CKP gap and the cam pulse bring the ECU into sync.
  2. Watch it warm up: cold-start enrichment, high idle and retarded spark for catalyst heating fade away. At 35 °C the ECU enters closed loop — the O2 sensor starts switching.
  3. Drive: pick a gear, press the pedal (hold W), brake with Space. Try WOT for power enrichment, release above 1700 rpm for decel fuel cut, hit the rev limiter.
  4. Turbo: switch engine type. See turbo lag, wastegate control, the blow-off valve, charge-air cooling and knock-limited spark.
  5. Break things: inject faults on the left and see how the ECU detects them, stores DTCs and falls back to backup strategies.
  6. Slow-mo: the crank-angle views run slowed down so you can follow each injection and spark. Pause (P) and drag across the timing scope to scrub the crank.

Keyboard: W/↑ throttle · Space brake · 0–5 gear · S start · P pause · C controls
